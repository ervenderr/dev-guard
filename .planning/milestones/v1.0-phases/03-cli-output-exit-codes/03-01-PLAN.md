- `sanitize(s: str) -> str`: first replace every backslash with two backslashes, then replace every non-printable character (per str.isprintable, which also catches lone surrogates from undecodable filenames) with its backslash escape (inner part of repr(ch), e.g. `\x1b`, `\n`, `\udcff`). Printable unicode stays as is. Escaping the backslash first makes the output unambiguous: a literal `\x1b` filename renders as `\\x1b`, a real ESC as `\x1b`.
- `run_scan(roots: list[Path], extra_files: Iterable[Path]) -> list[Finding]`: call scan(root, extra_files=...) once per root; pass extra_files only on the first call, () on the rest; merge into a set; return sorted by (SEVERITY_ORDER[f.severity], f.file, f.line, f.check_id, f.pattern). Do not mutate inputs.
- `format_table(findings: list[Finding]) -> str`: rows of (severity, check_id, f"{file}:{line}", pattern), each cell passed through sanitize; column widths = max len of header/cells; join cells with " | " using str.ljust, rstrip each line; append summary line f"{h} high, {m} med, {l} low". Empty list returns NO_FINDINGS_MSG. No color. Never include anything except these Finding fields (Finding has no matched text, keep it that way).
- `main(argv: list[str] | None = None) -> int`: parse (argparse SystemExit for bad flags propagates unchanged, exit 2). For each path, Path(p).expanduser(); if not exists or not is_dir: print f"dev-guard: {sanitize(p)}: no such directory" (or "not a directory") to sys.stderr and return EXIT_USAGE before scanning anything. Explicit paths use extra_files=(). Compute findings and the exit code (EXIT_HIGH if any severity == SEVERITY_HIGH else EXIT_CLEAN) BEFORE printing.
- Error handling in main (per orchestrator warning 6, Claude's discretion on cli internals):
  - Wrap print + an explicit sys.stdout.flush() in try/except BrokenPipeError: on BrokenPipeError, point stdout at devnull (os.dup2 of an os.devnull fd onto sys.stdout.fileno(), the Python-docs recipe, so the interpreter's exit-time flush does not raise again) and return the already-computed exit code; print nothing.
  - Wrap the scan/format work in an outer `except Exception as exc`: print exactly one line `dev-guard: internal error: {type(exc).__name__}` to stderr and return EXIT_INTERNAL. Do NOT print str(exc), repr(exc) or a traceback: exception text from decoders/parsers can contain scanned file content. This logs context (error type) without leaking content. Do not catch BaseException (SystemExit from argparse and KeyboardInterrupt keep default behavior).
- Never use subprocess/os.system/eval in cli.py; paths are only handed to scan().

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv PATH -> cli | user/cron-supplied paths, untrusted strings |
| scanned tree filenames -> terminal | attacker controls file and directory names inside scanned repos |
| scanner -> stdout/stderr | output may be copied into tickets/n8n; must hold only Finding fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering/Spoofing | format_table | mitigate | sanitize() escapes backslash first, then every non-printable char (ESC, CR, LF, tab, lone surrogates) in every cell; tests with "\x1b[31m", "\n" and literal `\x1b` |
| T-03-02 | Elevation of Privilege | cli.main path handling | mitigate | paths only passed to Path/scan(); no shell, subprocess, eval; grep gate in acceptance |
| T-03-03 | Information Disclosure | table output | mitigate | rows built only from severity/check_id/file/line/pattern; Finding has no matched-text field |
| T-03-04 | Denial of Service | nonexistent/non-dir path | mitigate | validated up front, stderr message, exit 2, no traceback |
| T-03-05 | Information Disclosure | stderr usage message | accept | echoes only the user's own sanitized argument |
| T-03-12 | Information Disclosure | unexpected exceptions | mitigate | catch Exception in main, print only exception type name, exit 70; no traceback/str(exc); test with DGSECRET_ marker in exception text; grep gate |
| T-03-13 | Denial of Service | closed stdout pipe (cron `| head`) | mitigate | BrokenPipeError caught around print+flush, stdout redirected to devnull, scan exit code returned; subprocess test |
| T-03-SC | Tampering | pip install -e . (setuptools build backend from PyPI) | accept | setuptools is the PyPA default backend, build-time only in pip's isolated env; no runtime dependency added |
</threat_model>
