Reporting these as malformed_json belongs to plan 01-02, so for now they return an empty list. Never let them raise. That gives one finding per distinct pattern per command.

Files come from iter_files(root), followed by extra_files. Explicit extra files may be symlinks (dotfile managers) but still go through read_text's regular-file and size checks, and missing ones are skipped. Dedupe by os.path.realpath. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scanned files → scanner | Every file under the root is attacker-controllable (a malicious package writes it) |
| filesystem layout → walker | Symlinks and huge files can be planted to redirect or stall the walk |
| findings → future output (Phase 3/4) | Anything stored in a Finding will be printed and POSTed to n8n |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | checks.py parsing | mitigate | Only `json.loads` on text. AST gate in tests/test_safety.py forbids subprocess/pty/eval/exec/compile/__import__/os.system/os.popen/os.exec*/os.spawn* in dev_guard |
| T-01-02 | Information Disclosure | Finding | mitigate | Finding has no matched-text field (5 fixed fields). test_safety asserts the fixture's fake secret never appears in repr/asdict, and the AST gate forbids `print` in dev_guard core |
| T-01-03 | Tampering / Info Disclosure | iter_files | mitigate | `os.walk(followlinks=False)` plus pruning symlinked dirs and skipping symlinked files, so planted links can't pull in files outside the root. Covered by test_walk |
| T-01-04 | Denial of Service | read_text | mitigate | stat size check against MAX_FILE_BYTES (1 MB) before reading. SKIP_DIRS prunes node_modules/.git. Covered by test_walk |
| T-01-05 | Denial of Service | regexes in H1_PATTERNS | mitigate | Patterns use no nested quantifiers and run only on commands from files of 1 MB or less |
| T-01-06 | Tampering | test fixtures | mitigate | Malicious fixtures use `.invalid` URLs only and are never executed. Nested `.claude/` dirs under tests/fixtures are not loaded by Claude Code (it only reads the project root `.claude/`) |
| T-01-SC | Tampering | pip install pytest | mitigate | Task 1 installs the exact name `pytest` (pypi.org/project/pytest, pytest-dev), the only package in the phase. Dev-only, isolated in `.venv` |
| T-01-13 | Denial of Service | json.loads + collect_commands | mitigate | One try around parse and recursive walk catches RecursionError (deep nesting) and ValueError (huge int literal), so a planted file under 1 MB can't crash scan(). test_walk covers both payloads |
</threat_model>
