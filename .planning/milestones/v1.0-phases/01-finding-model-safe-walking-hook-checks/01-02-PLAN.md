<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scanned JSON/JSONC → checks | Attacker controls structure (types, nesting, comments) as well as content |
| allowlist → severity | A wrong allowlist match downgrades a payload to no finding |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Spoofing | is_allowlisted | mitigate | Exact or prefix-plus-space match only, and SHELL_CHAIN_RE rejects `; & \| \` < > $(` and newlines, so `prettier && payload` isn't trusted. H1 high checks run regardless of the allowlist |
| T-01-08 | Tampering (evasion) | check_vscode_tasks | mitigate | Match on command plus args and on nested osx/linux/windows overrides. JSONC/malformed files fall back to raw line-by-line regex scan, so a `//` comment can't hide a payload |
| T-01-09 | Denial of Service | type-confused JSON (list/str where dict expected) | mitigate | isinstance checks on data, hooks, tasks, runOptions and args. Tests cover non-dict/non-list shapes so the whole scan can't be crashed |
| T-01-10 | Information Disclosure | new findings | mitigate | New findings reuse the 5-field Finding (pattern names only). The test_safety AST/no-print gate from 01-01 still runs in the full suite |
| T-01-11 | Elevation of Privilege | JSONC handling | mitigate | No JSONC library and no eval-based parsing. Raw text is only regex-searched |
| T-01-13 | Denial of Service | json.loads + recursive walks (collect_commands, iter_command_dicts) | mitigate | One try around parse and walk in both check_claude_settings and check_vscode_tasks catches RecursionError (deep `[` nesting) and ValueError (huge int literal) from files under 1 MB and reports low malformed_json. tasks.json then falls back to the raw line scan. Tests cover both payloads for H1 and H2 |
| T-01-14 | Tampering (evasion) | iter_command_dicts / command_parts | mitigate | Yield dicts with `command` OR `args`, and read str `value` from {value, quoting} objects, so args-only overrides and quoted-arg objects can't hide payloads. Tests cover both |
| T-01-15 | Spoofing | is_allowlisted prefixes | accept | `git -c alias.x='!...'` and `npx <pkg>` pass the prefix check. Known limit, marked with a `shortcut:` comment in code. H1 pattern checks still run on those commands |
| T-01-12 | Denial of Service | regex on raw lines | accept | Lines come from files of 1 MB or less (size cap in read_text), and the patterns have no nested quantifiers |
</threat_model>
