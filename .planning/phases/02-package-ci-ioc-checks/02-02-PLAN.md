In patterns.py add (all line regexes used with `.match` and anchored, so no per-position rescans, per warning 3):
- `CHECK_H4 = "H4"`; `WORKFLOW_SUFFIXES = (".yml", ".yaml")`; `WORKFLOW_DIRS = (".github", "workflows")`
- `OIDC_TOKEN_RE` = `ACTIONS_ID_TOKEN_\w+` (search; literal-led, linear)
- `PROC_MEM_RE` = `/proc/[^/\n]+/mem\b` (search; segment is any non-slash run so `/proc/$(pgrep -f Runner.Worker)/mem` matches, per warning 7)
- `USES_RE` = anchored `^\s*(?:-\s+)?uses\s*:\s*["']?(?P<ref>[^\s"'#]+)` (match)
- `RUN_KEY_RE` = anchored `^(?P<lead>\s*(?:-\s+)?)run\s*:(?P<value>.*)$` (match); the `run` key column is `len(m.group("lead"))`, i.e. for `- run: |` it is 2 right of the dash (warning 1)
- `BLOCK_SCALAR_RE` = `^[|>][+\-0-9]*\s*(#.*)?$` applied to `value.strip()` so `run: | # x` is a block (blocker 3)
- `SHA_RE` = `[0-9a-fA-F]{40}` used with fullmatch
- `PATTERN_ACTIONS_ID_TOKEN = "actions_id_token"`, `PATTERN_PROC_MEM = "proc_mem"`, `PATTERN_UNPINNED_ACTION = "unpinned_action"`; `LOCAL_ACTION_PREFIXES = ("./", "docker://")`

In checks.py add `check_workflow(path, text)`: iterate `text.split("\n")` with 1-based n (same line semantics as Phase 1) and strip a trailing `\r` from each line first (CRLF, blocker 3). Per line:
1. If len(line) > MAX_LINE_LEN: emit one low H4 PATTERN_OVERSIZE_LINE and skip all matching for that line (blocker 1 cap); it does not end an open run block.
2. OIDC_TOKEN_RE -> high H4 actions_id_token; PROC_MEM_RE -> high H4 proc_mem (any line, per CI-01 "echoing or reading").
3. Run-block tracking with `run_indent: int | None`: a line is blank iff `line.strip() == ""` (blank lines never end a block). While run_indent is set, a non-blank line whose indentation (`len(line) - len(line.lstrip())`) is greater than run_indent is a script line scanned with H1_PATTERNS (high H4, pattern = H1 name); a non-blank line with indentation <= run_indent ends the block and is then processed normally.
Steps 4-5 apply only to lines that are not run-block script lines.
4. RUN_KEY_RE match: if BLOCK_SCALAR_RE matches value.strip(), set run_indent = column of the `run` key; else scan the inline value with H1_PATTERNS (high H4).
5. USES_RE match: skip refs starting with LOCAL_ACTION_PREFIXES; otherwise ref = text after the last `@`; if no `@` or not SHA_RE fullmatch -> med H4 unpinned_action (actions/* included, per CONTEXT H4 decision).
Findings carry only pattern name + line.

Extend target_for: when `path.suffix.lower()` in WORKFLOW_SUFFIXES and `path.parent.name.lower() == "workflows"` and `path.parent.parent.name.lower() == ".github"` return `(CHECK_H4, check_workflow)`. Keep it after the TARGETS/package.json branches.

Run full suite. Commit: `feat: detect workflow token theft and unpinned actions (H4)`.
